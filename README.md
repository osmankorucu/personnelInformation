# personnelInformation

Personel yönetimi için Java JSF tabanlı web uygulaması. JPA/Hibernate ile veri yönetimi örnekleri içerir.

Özellikler
- Personel kayıt, listeleme, düzenleme ve silme işlemleri
- JSF tabanlı sayfa şablonları
- JPA/Hibernate ile veri erişimi

Teknolojiler
- Java
- JSF
- JPA / Hibernate

Çalıştırma
Projeye ait build/run yönergeleri proje yapılandırmasına göre değişir; IDE (Eclipse/IntelliJ) içinde çalıştırmak kolaydır.

Not
- README basit bir özet içerir; isterseniz daha ayrıntılı kurulum ve veritabanı konfigürasyonu ekleyebilirim.
